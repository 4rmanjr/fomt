# Peta simbol aset `0x70` ke berkas

**Dihasilkan otomatis**, jangan disunting tangan: `python3 tools/scripts/extract_assets.py`. Sumbernya manifest `assets/0x70/manifest.json` dari ekstraksi stream 0x70.

## Cara memperbarui

```sh
python3 tools/scripts/extract_assets.py              # ekstrak + dokumen ini
python3 tools/scripts/extract_assets.py --check-map  # exit 1 bila dokumen basi
```

## Ringkasan

| kelas | stream |
|---|---|
| palet | 20 |
| tile | 23 |
| peta | 91 |
| lain | 3 |

PNG: swatch palet 20, lembar tile 4bpp (abu-abu indeks) 23, peta berwarna 74, grid indeks (pasangan tidak terbukti) 17, tanpa PNG 3. Total 137 stream dari 53 simbol yang punya stream 0x70.

Pasangan peta: 74 terbukti (15 dari call site `Unpack`, 59 dari entri header), 17 tidak terbukti (jadi grid indeks).

## Simbol -> stream -> berkas

Path berkas relatif terhadap root repo. `stream` = urutan stream di dalam simbol (0 = paling awal). Pasangan palet/tileset diambil berurutan: (1) call site `Unpack`/salin di `asm/` yang menulis peta ke 0x0600C000-0x0600FFFF, dengan palet di 0x05000000 dan tileset di 0x06000000-0x0600BFFF dalam fungsi yang sama; (2) untuk stream container yang dialamatkan lewat pointer (tidak ada simbol statis), entri `gUnk_08105EDC` yang memuatnya sebagai lapis peta: +0x00 tileset, +0x04 palet, +0x0C/+0x10/+0x14 peta. Kolom bukti menyebut fungsi call site atau nomor entri header. Pasangan berupa alamat `0x08xxxxxx` adalah stream 0x70 di luar 53 simbol yang dibuka dari ROM saat render, bukan berkas hasil ekstraksi.
