# Peta simbol aset `0x70` ke berkas

**Dihasilkan otomatis**, jangan disunting tangan: `python3 tools/scripts/extract_assets.py`. Sumbernya manifest `assets/0x70/manifest.json` dari ekstraksi stream 0x70.

## Cara memperbarui

```sh
python3 tools/scripts/extract_assets.py              # ekstrak + dokumen ini
python3 tools/scripts/extract_assets.py --check-map  # exit 1 bila dokumen basi
python3 tools/scripts/extract_assets.py --check-png  # render ulang dari manifest (tanpa ROM)
python3 tools/scripts/extract_assets.py --check-external  # hash berkas extern
```

## Validitas PNG

Setiap entri PNG menyimpan `png_sha256` di manifest. `--check-png` merender ulang seluruh PNG dari `bin` stream dan `extern/*.bin` (tanpa membaca ROM), membandingkan hash hasil render dengan `png_sha256`, lalu memeriksa file PNG di repo terhadap hash yang sama. Ini menguji PNG langsung, bukan hanya hash palet/tileset pasangannya.

## Ringkasan

| kelas | stream |
|---|---|
| palet | 20 |
| tile | 23 |
| peta | 80 |
| layar | 11 |
| lain | 3 |

PNG: swatch palet 20, lembar tile 4bpp (abu-abu indeks) 23, peta berwarna 63, layar berwarna 11, grid indeks (pasangan tidak terbukti) 17, tanpa PNG 3. Total 137 stream dari 53 simbol yang seluruh isinya berformat `0x70`. Bank stream `0x70` tertanam di blob mentah diekstrak `embedded_streams.py` ke `assets/0x70/extern/` dan tidak dihitung di sini (lihat `ASET-0X70-TERTANAM.md`).

Pasangan peta: 63 pasangan byte-valid: 4 call site `Unpack`, 59 header-only (bukan call site; 41 interior, 18 eksterior), 17 tidak terbukti (jadi grid indeks).

Layar statis: 11 tilemap kelas `layar` (11 berpasangan) — bukan peta dan tidak dihitung di `peta berwarna`; call site-nya juga tidak masuk angka call site peta di atas.

## Bukti loader 59 peta header-only

Tidak ada call site `Unpack` yang menulis field lapis peta dari header langsung ke `0x0600xxxx`. Penelusuran jalur yang ada:

1. [`GetMapData`](../../asm/code_809E804.s#L11699) (`0x080A4698`) menghitung entri `gUnk_08105EDC` dengan stride 40 B; field `+0x0C`, `+0x10`, `+0x14` adalah tiga lapis peta.
2. [`func_080A5CC0`](../../asm/code_809E804.s#L14504) (`0x080A5CC0`) membaca ketiga field itu lalu memanggil [`Unpack`](../../asm/code_809E804.s#L14522) dengan tujuan `arg0+0x10`, `+0x14`, `+0x18` — buffer milik objek, bukan `0x0600xxxx`. Pemanggilnya `func_080A6660` dan `func_080CFBAC`; tidak ada tabel tujuan statis, tujuan berasal dari field objek.
3. Buffer itu dialokasikan [`func_080A4A94`](../../asm/code_809E804.s#L12283) lewat `__builtin_vec_new`, jadi tujuannya heap/RAM; tidak ada konstanta VRAM pada call site ini.
4. [`func_080A5EA0`](../../asm/code_809E804.s#L14751) (`0x080A5EA0`) memang menulis ke `0x06000000`, tetapi sumbernya field `+0x00` (tileset), bukan salah satu field lapis peta.

| field header | loader | tujuan |
|---|---|---|
| `+0x0C`, `+0x10`, `+0x14` | `func_080A5CC0` (`0x080A5CC0`) | `arg0+0x10/+0x14/+0x18` (buffer objek) |
| `+0x00` | `func_080A5EA0` (`0x080A5EA0`) | `0x06000000` (tileset) |

Karena itu 59 pasangan ber-header ditandai `pair_status: header-only`; bukti header tetap dipakai untuk memilih palet/tileset, tetapi tidak diklaim sebagai bukti call site ke VRAM. Angka 41/59 adalah distribusi interior/eksterior, bukan tingkat bukti.

## Simbol -> stream -> berkas

Path berkas relatif terhadap root repo. `stream` = urutan stream di dalam simbol (0 = paling awal). Pasangan palet/tileset diambil berurutan: (1) call site `Unpack`/salin di `asm/` yang menulis peta ke 0x0600C000-0x0600FFFF, dengan palet di 0x05000000 dan tileset di 0x06000000-0x0600BFFF dalam fungsi yang sama; (2) untuk stream container yang dialamatkan lewat pointer (tidak ada simbol statis), entri `gUnk_08105EDC` yang memuatnya sebagai lapis peta: +0x00 tileset, +0x04 palet, +0x08 palet kedua, +0x0C/+0x10/+0x14 peta, +0x20 lebar/tinggi, +0x24 flag interior/eksterior. Flag +0x24 hanya jenis peta, bukan tingkat bukti. Pasangan header-only tetap harus lolos pemeriksaan palet 480 B, tileset 32768 B, dimensi header, dan indeks tile di dalam tileset sebelum dirender. Eksterior memakai +0x08 sebagai varian palet musim (render memakai +0x04), interior memakai +0x08 sebagai palet kedua biasa. Kolom status menyebut `header-only` dan nama loader, bukan "terbukti call site". Pasangan berupa alamat `0x08xxxxxx` adalah stream 0x70 di luar 53 simbol; byte-nya disalin ke `assets/0x70/extern/` dan direferensikan lewat `bin` + `sha256`, bukan dibuka ulang dari ROM saat render. Aset eksternal itu juga dicatat di `external_assets` manifest dengan `unpacked`/`raw_bytes` dan `sha256`, sehingga `--check-external` cukup memeriksa berkas tanpa menebak alamat.
