3. **`func_08003E88` (new_game.s, 100B) MATCH lalu migrasi `src/`.**
   Draf m2c awal salah tipe (`GenObj *sp0` dipakai `sp0.unk0`), return type
   `void` (`pop {r0}` = epilog void), dan struktur stack 2 word.
   Jalan menuju MATCH (22 residual regalloc -> 9 -> 5 -> 2 operand -> 0):
   pin `var_r4` ke `r4`; urutkan load byte sebelum hitung shift; hindari base
   pointer stack yang hidup melewati `bl`; pin `p1` ke **base** `sp` (bukan
   `sp+4`) supaya keluar `mov r2, sp ; ldrh r1, [r2, #4]`; pin temp rantai
   byte `r1`, temp shift `r0`, konstanta mask `r0`, nilai termask `r2`; dan
   fence `__asm__ volatile("" : "+m"(st[0]))` untuk memaksa reload slot stack
   yang di ref memang dimuat ulang. Pola ini masuk `POLA-DIFF.md` §33.
4. **Gerbang migrasi (temuan operasional):** blok ditolak karena `src/` sudah
