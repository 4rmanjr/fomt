## Lanjutan 30: `func_08005A58` — hipotesis post-increment diuji, ternyata wall codegen

Hipotesis di note shard (salinan 13 byte lewat pointer post-increment tanpa variabel lokal tambahan,
lalu pin `arg0`→r5 / `arg1`→r8) dijalankan: prolog sudah cocok, sisi sumber salinan kini memang

(`ldr rX,=0x4628; add; strb [rX]`) sehingga ref (`strb r0,[r1]`) tak tercapai: 89 instruksi vs 88.

struct ke kelipatan 4 (sizeof 3/5/13 → 4/8/16; salinan struct 2/5/9/13 byte → 1/2/3/4 kata),

dan frontend C++ (`agbcp`) identik. Pemindaian 3.129 pasangan `ldm …!`/`stm …!` di `asm/*.s`
menemukan pola ekor byte hanya **1×**, yaitu fungsi ini.

`func_08005A58` menjadi **7** (6 sebelumnya di Lanjutan 29). Draf dipertahankan sebagai V2

fungsi diparkir sebagai wall codegen; rincian di `POLA-DIFF.md` §58 (ringkas di §45).
