## Temuan / pelajaran

> Sejak sesi ini pola **tidak lagi** ditumpuk di `AGENTS.md`.
> Katalog: `docs/decomp/POLA-DIFF.md` (codegen) dan
> `docs/decomp/MIGRATE.md` (gerbang migrate). AGENTS.md hanya memuat
> ringkasan 4 pola tersering + aturan anti-menumpuk.

1. **Epilog `pop {r1}; bx r1` ⇒ fungsi MENGEMBALIKAN nilai (`s32`).**
   Draf m2c `void f(){call();}` menghasilkan `pop {r0}` → residual 1 byte
   (`byte +0x1a: 0x1 vs ref 0x2`). Fix: `s32 f(){return call();}`.
   Terbukti 5 fungsi. Varian: ekor `ldr r1,[r0,#N]; asrs r0,r1,#0x10`
   ⇒ `return a >> 16;` dgn `s32 a = 0;` **sesudah** call (kalau sebelum,
   gcc menaruhnya di r4 + `push {r4}`).
2. **Target indirect call di `r2` padahal `r1` bebas ⇒ ada ARGUMEN KE-2
   yang diteruskan apa adanya.** m2c membuangnya (tak dipakai di badan).
   Tambah `s32 arg1` + teruskan (`fn(t, arg1)`) → zero codegen, target
   pindah ke r2. `movs r1,#0` di ref = init variabel hasil.
   Ini menyelesaikan `func_080120A4`/`080120C4` setelah 4 attempt gagal
   dgn pin/temp/`register __asm__` (pin TIDAK bisa memindahkan ini).
3. **Guard migrate membandingkan STRING tanda tangan extern** dgn `src/`
   (`s32`→`i32` auto, `u32` vs `s32` TIDAK). Kasus `GetMapData`:
   src `void *GetMapData(i32)` vs draf `MapData *GetMapData()` → SKIP.
   Fix codegen-netral: pakai tanda tangan src + lewatkan nilai balik call
   sebelumnya via satu variabel sekali-pakai (`t = f(...); return
   ((MapData*)GetMapData(t))->unk20 << 3;`) — r0 sudah berisi `t`.
4. **`fomt --migratable` bisa “MATCH” fungsi yang SUDAH ada di src**
   (state shard basi; judge lihat “no ref symbol”). Efek: blok DUPLIKAT
   masuk `decomp/promoted/<stem>.cc` (sesi ini 12 blok di game_state,
   + `free`/`func_08009674` di 3 modul) → wajib `git diff
   decomp/promoted/` sesudah batch dan revert; “MATCH” itu BUKAN migrasi
   (`migrate.py` menjawab `sudah ada di src/... (dilewati)`).
   Sesi-sesi sebelumnya sempat melaporkan ini sebagai migrasi — salah.
5. **Insert ke `src/*.cc` yang punya blok `extern "C" {` bisa MERAH**
   (`syntax error before 0x5F0`, kasus `func_080AAF3C` di
